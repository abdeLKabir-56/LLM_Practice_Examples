# LLM Practice Examples

This repository contains small examples for practicing with large language models (LLMs) and related tools, including:

- LangChain
- ChromaDB and embeddings
- MCP (Model Context Protocol)
- LangGraph
- Retrieval-augmented generation (RAG)

Feel free to use these examples to learn and experiment. This repository is a collection of practice examples, not a complete end-to-end project.
